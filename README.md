# Between Holds / 岩点之间 3.1

A short browser game about climbing, calculation, memory, and divided attention.

一款关于攀岩、计算、记忆与注意力分配的网页小游戏。

## Play / 游玩

Hold A, Space or the left mouse button. Release while the marker is in green. Remember the six cards that briefly appear beside the climbing route; answer the recall questions afterward.

按住 A、空格或鼠标左键，在指针进入绿色区时松开。六张卡片会在抓稳岩点、身体上移时浮现，每张至少显示 6.5 秒；卡片切换避开精准松手区，结束后回忆答题。

Version 3.1 enlarges the climber and cards. Cards appear after a secure grip and stay for at least 6.5 seconds; changes avoid the critical release window. The climb lasts up to 65 seconds.

## Publish with GitHub Pages

1. Upload all files and folders in this directory to the root of a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then click **Save**.
5. Wait briefly for GitHub to display the public website address.

No build command or server is required.
